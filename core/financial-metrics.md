# Financial Metrics · 财务指标分析手册（v0.9.5 新增）

> 被 `sm-company-deepdive` / `sm-model-check` / `sm-valuation` / `sm-earnings-preview` 引用。
> 目标：规定"每个主要财务指标**怎么看**"——看什么、和谁比、什么算警报，而不是把指标表罗列一遍完事。
> 通用纪律：任何指标**单期数值无意义**，必须同时给（1）近 3-5 年趋势（2）同行对比（3）异常解释。

---

## §1 成长性

| 指标 | 怎么看 | 警戒信号 |
|---|---|---|
| 收入增速 | 拆内生 vs 并购；拆量 vs 价（见 moat-analysis §4）；对比行业增速判断份额得失 | 收入增长全靠并购；量增价跌被总数掩盖 |
| 归母净利增速 | 与收入增速对比看经营杠杆；剔除一次性损益（政府补助 / 资产处置 / 公允价值变动）看核心利润 | 利润增速长期跑赢收入却无毛利率改善解释 |
| 合同负债 / 存货 / 在建工程 | 前瞻指标：合同负债增 → 订单在手；备货性存货增 → 对需求乐观；在建转固节奏 → 产能释放时点 | 存货增速远超收入且非备货逻辑 |

## §2 盈利能力

| 指标 | 怎么看 | 警戒信号 |
|---|---|---|
| 毛利率 | 用毛利桥拆驱动（量 / 价 / 成本 / 结构）；与最接近的同行逐年比，差距即壁垒的财务表达 | 无解释的骤升骤降；靠会计口径调整（运费重分类等） |
| 净利率 / 经营利润率 | 看毛利率之下费用率的挤压或释放；区分经营性与非经常性 | 净利率改善全来自非经常损益 |
| ROE（杜邦拆解） | 必拆三因子：净利率 × 周转率 × 权益乘数，判断 ROE 质量。靠杠杆撑起的高 ROE ≠ 靠净利率的高 ROE | 净利率、周转率双降而 ROE 靠加杠杆维持 |
| ROIC | 与 WACC 比较判断是否创造价值；重资产公司比 ROE 更真实 | ROIC 持续低于 WACC 却持续大额 capex |
| 研发费用率 | 结合资本化率看真实投入；绝对额 vs 竞对（小基数高费率可能绝对额仍不够看） | 研发资本化率突然抬升以美化利润 |

## §3 营运效率

| 指标 | 怎么看 | 警戒信号 |
|---|---|---|
| 存货周转天数 | 分行业看：硬件看跌价风险与备货节奏；分结构看原材料 / 在产品 / 库存商品，原材料增 = 主动备产，库存商品增 = 卖不动 | 库存商品占比抬升 + 周转放缓 + 跌价准备计提不足 |
| 应收周转天数 | 与收入确认政策一起看；对比同行判断产业链话语权 | 应收增速远超收入（可能压货 / 放宽信用刺激收入） |
| 应付周转天数 | 上游话语权的体现；与现金循环周期（CCC = 存货 + 应收 − 应付天数）合并判断 | 靠拖欠上游改善现金流 |
| 固定资产周转率 | 重资产公司核心：产能利用率的财务映射；新产能爬坡期会自然下降，要区分爬坡与需求不足 | 持续扩产但周转率长期下行 |

## §4 现金流质量

| 指标 | 怎么看 | 警戒信号 |
|---|---|---|
| 经营现金流 / 净利润 | 长期应 ≥ 0.8（重折旧行业应 > 1）；低于则利润含金量存疑，去营运资本里找原因 | 连续 2 年 < 0.6 且解释不了 |
| 自由现金流（FCF） | OCF − capex；成长期为负可接受，但要看 capex 是否对应可验证的订单 / 需求 | 常年负 FCF + 靠融资续命 + 需求证据弱 |
| Capex / 折旧比 | > 1 = 扩张期，< 1 = 收缩 / 收获期；与管理层产能指引交叉验证 | capex 高峰撞上行业景气顶点 |
| 分红 + 回购率 | 现金创造能力的最终证明；与账上现金、有息负债合并看 | 高分红同时高有息负债（借钱分红） |

## §5 偿债与资本结构

| 指标 | 怎么看 | 警戒信号 |
|---|---|---|
| 资产负债率 | 拆有息 vs 无息（经营性占款是好负债）；有息负债率与同行比 | 有息负债率快速抬升且投向低 ROIC 项目 |
| 净负债 / EBITDA | 偿债压力核心指标，> 3 需警惕（分行业） | 叠加利率上行周期 |
| 利息保障倍数 | EBIT / 利息费用，< 3 进入脆弱区 | 盈利下行期加速恶化 |
| 商誉 / 净资产 | 并购型公司必查；结合被购标的业绩承诺完成度 | 商誉占比高 + 承诺期刚过 |

## §6 分行业侧重（TMT / 硬件为主的差异化清单）

- **硬件 / 制造**：毛利率与良率、存货结构、产能利用率、capex 节奏、ASP 年降 —— 核心矛盾是"扩产周期 vs 需求周期"的错配
- **半导体**：库存天数（全产业链口径）、B/B 值、先进制程占比；周期位置判断优先于单期业绩
- **软件 / SaaS**：合同负债与续费率、研发资本化、经营现金流优先于利润；PS/PSG 口径下收入质量 > 利润
- **互联网 / 平台**：用户 × ARPU 拆分、获客成本回收期、非 GAAP 调整项要逐项拆
- **消费**：渠道库存（报表看不见的存货）、经销 vs 直营口径、提价能力

## §7 使用纪律

1. 不做"指标全家桶"式罗列——按当期研究问题挑 **3-8 个决定性指标**深挖（deepdive §6 默认 3-5 个），其余略过
2. 每个引用的指标必须落到结论：这个数**支持还是削弱**投资命题？
3. 指标异常必须给出解释或标注"待核验假设"，禁止视而不见
4. 同行对比选取的可比公司与 `sm-valuation` 的可比池保持一致
