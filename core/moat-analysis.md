# Moat Analysis · 核心壁垒分析框架（v0.9.5 新增）

> 被 `sm-company-deepdive`（公司层）和 `sm-industry-map`（行业层）共同引用。
> 目标：把"这家公司有壁垒"从一句套话变成**可量化、可比较、可证伪**的分析模块。
> 所有量化结论必须带完整中文证据等级（公开事实 / 财报披露 / 市场共识 / 合理推演 / 待核验假设）。

---

## §0 适用性闸门（v0.9.8 新增 · 先看这个再决定做多深）

本框架的 §1-§2 是**理解工具**，§3-§4 是**测算工具**。测算工具只有在数据撑得住时才有价值——AI 没有渠道调研、专家访谈和自建模型，强制拆表的结果是"看起来精确、层次很浅"。因此：

| 模块 | 默认深度 | 升级到完整量化的条件 |
|---|---|---|
| §1 壁垒五维 | 只展开决定性的 1-2 维并量化，其余一句话 | — |
| §2 竞对差距 | 定性差距 + 关键锚点（份额 / 毛利率 / 代际），触发条件必写 | 2-3 家竞对关键维度都有一次源数据 → 做完整差距表 |
| §3 市场空间 | 数量级区间 + 来源 + 量价方向 | 行业总量 / 渗透率 / ASP 有产业数据库原表或公司披露 → 做逐年表 + 交叉验证 |
| §4 盈利预测量价拆分 | 分业务线写量靠什么、价往哪走、弹性最大变量 | 公司披露量价 / 用户给模型 / 用户明示"带量价拆分" → 做逐年表 + 毛利桥 |

**数据可得性闸门**：表格里每个量、价、份额假设必须指到一次源或用户给定假设；指不到的格子写"待核验假设（缺一次源）"或留空，禁止为了填满表而拍数。一张表待核验格子 > 1/3 → 退回默认深度，并在"仍需补的资料"里写明缺什么。

**写作顺序**：先把业务理解（各业务做什么、前景、技术变化传导）写透，再决定要不要测算；测算是理解的延伸，不是替代。

## §1 壁垒五维拆解（公司层必做）

每一维都要回答三个问题：**壁垒是什么 → 有多高（量化）→ 会不会被侵蚀（触发条件）**。

### 1.1 市场地位

- 全球 / 区域市占率（近 3 年趋势，不只报当期数）
- 行业排名 + 与第二名的份额差距
- 定价权证据：提价历史、涨价函、毛利率在成本上行期的表现
- 客户集中度反向验证：是公司绑定客户，还是客户绑定公司？

### 1.2 品牌 / 客户认知

- 品牌溢价：同规格产品 ASP 高出同行多少 %
- 复购率 / 客户留存率 / NPS（如可得）
- 认证与准入：进入大客户供应链的认证周期（车规、医疗、云厂商合格供应商等）
- B 端生意注意：品牌壁垒常表现为"采购不选它要担责"的默认选项地位

### 1.3 技术壁垒

- 研发投入：研发费用率 vs 同行、研发人员数量与结构
- 专利：数量只是起点，重点看核心专利族 + 是否卡住行业标准
- 工艺 / 良率：量产良率 vs 同行（硬件公司最硬的壁垒之一）
- 技术代际：领先同行几代 / 几年？下一代技术路线上是否仍领先
- 迭代速度：新品推出节奏 vs 同行

### 1.4 成本 / 规模壁垒

- 单位成本 vs 同行（可用毛利率差近似反推）
- 规模效应来源：采购议价、产能利用率、折旧摊薄、学习曲线
- 垂直一体化程度及其成本贡献

### 1.5 转换成本 / 生态绑定

- 客户切换供应商的实际成本：重新认证周期、产线改造、软件适配
- 生态位：是否嵌入客户的设计（design-in）/ 工作流 / 数据
- 长协 / 绑定性合同占收入比重

> ⚠️ 五维不必平均用力。先判断该商业模式下**哪 1-2 维是决定性的**（硬件多为技术 + 成本，消费多为品牌 + 渠道，平台多为网络效应 + 转换成本），把火力集中在决定性维度。

## §2 竞争对手差距量化（必做，禁止定性带过）

选 2-4 家主要竞争对手，做**差距量化表**：

| 维度 | 本公司 | 竞对 A | 竞对 B | 差距结论 |
|---|---|---|---|---|
| 市占率（近 3 年） | | | | 领先 / 落后 X pct，趋势扩大 / 收窄 |
| 毛利率 | | | | 差 X pct → 反映成本 / 定价权差距 |
| 研发费用率 & 绝对额 | | | | 投入差距能否维持技术代差 |
| 技术代际 / 良率 / 关键参数 | | | | 领先约 X 代 / X 年 |
| 产能 & 扩产计划 | | | | 供给端追赶时间表 |
| 大客户重合度 | | | | 正面竞争还是错位竞争 |

**必答的收口问题**（差距量化的意义所在）：

1. 竞对追平本公司当前水平需要**几年 + 多少资本开支**？（合理推演，写出推演依据）
2. 差距在**扩大还是收窄**？最近一年的边际证据是什么？
3. 壁垒失效的**可观测触发条件**：出现什么信号（竞对良率爬坡、份额拐点、大客户导入二供）说明壁垒正在被侵蚀？

## §3 市场空间测算（量价拆分法）

### 3.1 基本框架

```
市场空间 = 量 × 价
  量：出货量 / 装机量 / 用户数 / 渗透率 × 基数
  价：ASP 及其趋势（升级带来的价增 vs 竞争带来的价减）
```

分三层：**TAM**（理论总空间）→ **SAM**（公司可服务空间）→ **SOM**（份额假设下可获得空间）。外发口径至少给到 SAM。

### 3.2 测算纪律

1. **自上而下 + 自下而上双向交叉验证**，两个口径差异 > 30% 时必须解释原因
   - 自上而下：行业总量（权威机构 / 产业数据库）× 细分占比 × 渗透率
   - 自下而上：核心客户 / 项目逐个累加（客户 capex × 采购占比 × 公司份额）
2. 量、价假设**分开列**，每个假设标证据等级，禁止只给一个终值
3. 给出 3-5 年的年度路径（不只给终局数），标明拐点年份及其驱动
4. 敏感性：量、价各取悲观 / 中性 / 乐观三档，给出空间区间而非单点

## §4 盈利预测量价拆分（公司层必做）

### 4.1 收入拆分

按业务线逐条拆 `收入 = 量 × 价`：

| 业务线 | 拆分维度 | 量的驱动 | 价的驱动 |
|---|---|---|---|
| 例：光模块 | 800G / 400G / 200G 分档 | 各档出货量（跟客户 capex） | 各档 ASP 年降幅 + 结构升级 |
| 例：代工 | 分制程 | 产能 × 利用率 | 分制程 ASP |

- 量的假设要能挂到**可跟踪的前瞻指标**（客户 capex、订单、产能爬坡时间表）
- 价的假设要区分**同款年降**与**结构升级**两个方向的力，净效应写清楚
- 结构变化（高价品占比提升）单独列一行，不要混进 ASP

### 4.2 利润拆分

```
毛利桥：上期毛利率 → 量升摊薄折旧 ± ASP 变动 ± 成本变动 ± 结构变化 → 本期毛利率
```

- 每座"桥墩"给出幅度估计与依据
- 费用率与收入增速的剪刀差 → 经营杠杆弹性
- 最后收口：**利润弹性最大的单一变量是什么，其 ±10% 对净利润影响多少 %**

### 4.3 与市场空间联动自检

- 公司收入预测 ÷ 市场空间测算 = 隐含份额，逐年检查是否越界（隐含份额超过 §2 竞争格局支持的水平 → 预测过于激进）
- 盈利预测的量假设与 §3 的量假设**必须同源**，不允许两处用不同口径

## §5 常见错误（自检清单）

- [ ] ❌ 壁垒写成形容词堆砌（"技术领先、客户优质"）而无一个量化锚
- [ ] ❌ 只写公司强在哪，不写竞对差多远、追上需要多久
- [ ] ❌ 市场空间只有一个终局大数（"千亿市场"），无量价假设、无年度路径
- [ ] ❌ 收入预测与市场空间测算脱节，隐含份额没人算过
- [ ] ❌ 把管理层口径的份额 / 空间数字直接当事实（应标"待核验假设"并找第三方交叉）
- [ ] ❌ ASP 假设忽略年降（硬件常见错误）或忽略结构升级（只线性外推降价）
- [ ] ❌ 没有一次源却把量价表填满（数字看起来精确、实际全是拍的）——应退回默认深度
- [ ] ❌ 测算篇幅压过业务理解：读者看完表格还是不知道这家公司每块业务在发生什么、技术变化为什么利好或利空
