# SM Company Deepdive

这个 skill 用于公司层面的深度研究，不写空泛概述，要尽量回答"为什么是这家公司，而不是别人"。

**v0.9.5 升级重点**：核心壁垒从一段扩为独立大模块（五维拆解 + 竞对差距量化 + 市场空间量价拆分），盈利预测强制量价拆分，新增财务指标分析段。

## 强制流程（v0.9.5 硬约束）

> ⛔ **任何分析输出之前**，必须严格执行 [`../../core/preamble.md`](../../core/preamble.md) 的 6 步开始前流程
>
> ⛔ **任何输出完成之前**，必须严格执行 [`../../core/postamble.md`](../../core/postamble.md) 的 8 步结束后流程
>
> 输出归档按 [`../../core/output-archive.md`](../../core/output-archive.md) 命名规范
> 输出验收按 [`../../core/acceptance.md`](../../core/acceptance.md) 清单逐条自检
>
> **跳过任何一环视为未完成任务。**

Company Deepdive 是最吃数据的 skill，缺数据时**严禁**开始输出结论。如果 preamble 拿不到关键数据（最近一期财报、股东、可比公司），必须走兜底协议让用户贴材料。

**壁垒与量价拆分模块**必须先读 [`../../core/moat-analysis.md`](../../core/moat-analysis.md) 全文；**财务指标分析段**必须先读 [`../../core/financial-metrics.md`](../../core/financial-metrics.md)。

适用场景：

- 覆盖启动
- 公司更新
- 财报前准备
- 可比公司比较

## 必答问题

- 公司在产业链里的位置是什么
- 收入增长靠什么驱动（量还是价，各贡献多少）
- 利润弹性来自哪里
- **公司的核心壁垒是什么，量化到什么程度**（哪 1-2 维是决定性的）
- **主要竞争对手离它有多远**（份额 / 毛利率 / 技术代际差距 + 追平需要几年）
- **市场空间有多大**（量价拆分 + 双向交叉验证 + 隐含份额自检）
- 主要财务指标在说什么（支持还是削弱命题）
- 市场当前为什么关注它
- 下一个验证节点是什么

## 输出格式（13 段）

- `§1 公司定位`（产业链位置 + 一句话商业模式）
- `§2 业务拆分`（各业务收入 / 毛利占比 + 增速）
- `§3 核心壁垒五维拆解` ★ — 按 moat-analysis §1：市场地位 / 品牌 / 技术壁垒 / 成本规模 / 转换成本，先声明哪 1-2 维是决定性的并集中量化
- `§4 竞争对手差距量化` ★ — 按 moat-analysis §2：差距量化表 + 追平年限与资本推演 + 壁垒侵蚀的可观测触发条件
- `§5 市场空间测算` ★ — 按 moat-analysis §3：TAM/SAM/SOM，量价拆分，自上而下 + 自下而上交叉验证，3-5 年年度路径 + 三档敏感性
- `§6 收入预测量价拆分` ★ — 按 moat-analysis §4.1：分业务线 量 × 价 逐条拆，量挂前瞻指标，价分年降与结构升级
- `§7 利润预测拆分` ★ — 按 moat-analysis §4.2：毛利桥 + 费用剪刀差 + 利润弹性最大的单一变量及其 ±10% 影响
- `§8 财务指标分析` ★ — 按 financial-metrics 手册挑 5-8 个决定性指标：趋势 + 同行对比 + 结论（支持 / 削弱命题），异常必须解释
- `§9 风险点`（可观测、可触发，不写套话）
- `§10 市场关注焦点`
- `§11 与可比公司的关键差异`（与 §4 竞对池同源）
- `§12 未来三个月跟踪指标`
- `§13 仍需补的资料`

★ = v0.9.5 强化模块。§5 的量假设与 §6 必须同源；§6-§7 的预测收入 ÷ §5 市场空间 = 隐含份额，逐年自检不越界。

## 约束

- 没有证据时，不要假设客户、订单或份额变化
- 避免把管理层表述直接当成事实（管理层口径的份额 / 空间数字标"待核验假设"并找第三方交叉）
- 优先突出影响盈利和估值的变量
- 壁垒禁止形容词堆砌——每一维至少一个量化锚，否则该维写"暂无量化证据"
- 市场空间禁止只给终局大数——必须有量价假设、年度路径、区间
- 关键事实必须带完整中文证据等级（公开事实 / 财报披露 / 市场共识 / 合理推演 / 待核验假设）
- 输出前过一遍 moat-analysis §5 常见错误自检清单
