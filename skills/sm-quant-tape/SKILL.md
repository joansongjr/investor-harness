# SM Quant Tape（量化看盘 · 缠论结构）

> 与 `sm-tape-review`（常规技术面：均线 / MACD / KDJ / 关键位）互补。
> 本 skill 专做**缠论走势结构**：把 K 线序列标注成分型 → 笔 → 线段 → 中枢，判断当前走势类型和所处位置，识别三类买卖点与背驰。
> ⛔ 缠论标注**只能基于真实 OHLC 数据逐根推导**，禁止凭印象说"这里有个中枢"。

## 强制流程（v0.9.5 硬约束）

> ⛔ **任何分析输出之前**，必须严格执行 [`../../core/preamble.md`](../../core/preamble.md) 的 6 步开始前流程
>
> ⛔ **任何输出完成之前**，必须严格执行 [`../../core/postamble.md`](../../core/postamble.md) 的 8 步结束后流程
>
> 输出归档按 [`../../core/output-archive.md`](../../core/output-archive.md) 命名规范
> 输出验收按 [`../../core/acceptance.md`](../../core/acceptance.md) 清单逐条自检
>
> **跳过任何一环视为未完成任务。**

Quant Tape 特别注意：
- preamble 取数必须拉到**完整 OHLC + 成交量序列**（默认日线 120 根），拉不到就走兜底协议让用户贴数据，**严禁**无数据硬标
- 本机装有 `chan-theory` skill 时优先调用它做结构标注，本 SKILL.md 负责投研纪律（证据、归档、一致性检验）
- preamble Step 2 读取该公司最新 sm-thesis / sm-company-deepdive 输出，用于 §6 一致性检验

## 适用场景

- "看一下 X 的缠论结构" / "X 走到哪一段了"
- 加减仓前找结构性买卖点（配合基本面方向）
- 中枢震荡 vs 趋势离开的判断："现在是盘整还是走趋势"
- 大级别背驰提示的风险预警

## 不适用场景

- ❌ 分钟级日内交易信号（最小级别 30 分钟）
- ❌ 脱离数据的"盘感"式论断
- ❌ 用缠论结论替代基本面研究（结构只回答"位置与时机"）

## 输出格式（7 段）

### §1 数据与级别声明

```
标的：{代码 名称}
级别：{日线 / 30min / 周线}；回看：{N} 根
数据区间：{起} ~ {止}；数据源：{iFind / gangtise-data / 用户提供}
包含关系处理：已按缠论规则合并 K 线，合并后 {M} 根
```

### §2 分型 / 笔 / 线段标注

- 关键顶分型 / 底分型清单（日期 + 价位），只列影响当前结构的
- 当前有效笔序列（最近 5-9 笔：起止日期、起止价、方向、幅度）
- 线段划分及当前线段方向

### §3 中枢判定

```
当前中枢：{ZG 上沿 / ZD 下沿 / ZZ 中轴}（由笔 {a}-{b}-{c} 重叠构成）
中枢级别：{本级别 / 升级}
价格相对中枢位置：中枢上方 / 内部 / 下方
中枢演化：延伸（第 N 段）/ 新生 / 扩展
```

### §4 当前走势类型

- 上涨 / 下跌 / 盘整，走势的完成度判断（走势终完美的当下状态）
- 多级别联立（如做了次级别）：本级别与次级别方向是否一致

### §5 买卖点识别

| 类型 | 位置 | 条件是否满足 | 依据 |
|---|---|---|---|
| 一类买/卖点 | 趋势背驰点 | ✅/❌/待确认 | 背驰证据（§6）|
| 二类买/卖点 | 一类后次级别回抽 | ✅/❌/待确认 | 回抽不破前低/前高 |
| 三类买/卖点 | 离开中枢后回抽不回中枢 | ✅/❌/待确认 | 回抽低点 > ZG（买）/ 回抽高点 < ZD（卖）|

⚠️ "待确认"必须写清**确认条件**（什么价位 + 什么形态出现算确认）。

### §6 背驰检验 + 量能交叉验证

- 背驰判断：比较前后两段同向走势的 MACD 面积 / 斜率 / 幅度（写出具体数值对比，禁止只说"有背驰"）
- 量能配合：进入中枢缩量 / 离开中枢放量是否成立
- 与基本面一致性：结构信号（如三买）与 thesis 方向同向 → 时机配合；背离（基本面看多但出现大级别顶背驰）→ 提示重检命题或标注观察期

### §7 观察触发（收口）

```
如果 {价格突破 X 且不回中枢} → 三买确认 → 意味着 {结构走强}
如果 {跌回中枢 ZG 之下} → 三买失败 → 退回中枢震荡处理
如果 {新高但 MACD 面积萎缩} → 顶背驰警报 → 结合基本面决定减仓评估
下一根关键 K 线看：{具体条件}
```

## 约束

- ❌ 严禁无 OHLC 数据做任何结构标注
- ❌ 严禁只给结论不给推导（每个分型 / 中枢都要有日期 + 价位依据）
- ❌ 严禁"必涨 / 必跌 / 买点已现赶紧买"式表述；买卖点是**结构位置描述**，不是操作指令
- ❌ 严禁在外发研报中引用缠论结论（仅限内部看盘参考，见 compliance）
- ✅ 涉及加减仓含义的输出必须带"需人工复核"标注
- ✅ 与 sm-tape-review 结论冲突时，两者并列呈现，不强行调和
